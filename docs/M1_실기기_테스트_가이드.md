# M1 실기기 도보 테스트 가이드

대상: 다니엘 쌤 (M1 완료 기준의 실기기 검증 항목 — 지시서 7장)
전제: 스마트폰 2대 (지불 왕복 테스트용), 같은 Wi-Fi에 연결된 개발 PC

## 앱 실행 방법

```
cd shvil-dev
npm install
cd apps/wallet
npm start          # Expo 개발 서버 시작
```

- 폰에 **Expo Go** 앱을 설치하고 터미널의 QR을 스캔하면 앱이 열립니다.
- 위치·모션·카메라 권한을 모두 허용해 주세요 ("정밀 위치" 필수).

### 현재 제약 (Expo Go)

- **포그라운드 추적**: 화면이 켜져 있는 동안 걷기 기록이 동작합니다.
  백그라운드 상시 동작(만보기 모드 완성형)은 개발 빌드(dev build)가 필요하며
  M1 후속 항목입니다.
- **샘플 코스**: 현재 내장 코스는 쉬빌 이스라엘 북부의 *예시* 폴리라인입니다
  (결정 대기 6번 — 파일럿 구간 확정 시 교체). 국내 테스트 시에는
  `apps/wallet/src/walk/data/shvilIsraelSample.ts`의 좌표를 걸으실 동네
  산책로 좌표로 바꾸면 동일하게 검증할 수 있습니다.

## 검증 항목 (지시서 7장 M1 완료 기준)

| # | 항목 | 절차 | 기대 결과 |
|---|---|---|---|
| 1 | 코스 위 인정 | 홈에서 "걷기 추적 시작" 후 코스 폴리라인 위를 500m 이상 걷기 | 걷기 탭에 "코스 위 — 인정 중", 홈의 잠정 SHV가 1km당 1 SHV 비율로 증가 |
| 2 | 코스 밖 제외 | 코스에서 200m 이상 벗어나 걷기 | "코스 밖 — 감액 중" 표시, 잠정 증가율이 1/10로 급감 |
| 3 | 엔젤 우회 잠정 | 코스를 벗어나 등록 엔젤 포인트 방향으로 걷기 | "엔젤 우회 — 잠정" 표시, 홈에 "엔젤 우회 잠정 ○ SHV — 사용 시 확정" |
| 4 | 차량 제외 | 추적 켠 채로 차량 이동 | 잠정 SHV 증가 없음 (속도 필터가 창을 거부) |
| 5 | 수동 정산 | 걷기 탭 → "여기서 정산" | 잠정이 0으로 리셋되고 지갑에 "걸음 생성" 코인 추가, 계보에 거리·날짜만 표시 |
| 6 | 비행기 모드 지불 왕복 | 두 폰 모두 비행기 모드. A(수령 탭): 잠자리 10 → 청구 QR. B(지불 탭): 스캔 → 지불 → 지불 QR. A: 역스캔 → 확인 QR. B: 확인 스캔 | 서버·통신 없이 완결. A 지갑에 10 SHV(생성 회원 번호는 B), B 지갑에서 차감 + 잔돈 코인 |
| 7 | 이중 사용 거부 | 6 완료 후 B가 같은 코인으로 다시 지불 시도(새 청구) | A의 역스캔에서 "이미 수령한 코인" 거부 |
| 8 | 가짜 위치 차단 | (Android) mock location 앱 켜고 걷기 | 걷기 탭에 "가짜 위치 감지" 경고, 잠정 증가 없음 |

## 변조 앱 코인 거부 시연 (항목 9)

M1에서는 단위 테스트로 시연됩니다 (`packages/shared` 위조 코인 거부 6종 +
`apps/wallet` 회랑 테스트). 실제 변조 APK 시나리오는 Play Integrity / App Attest
연동(결정 대기 3번, M2 보안 단계) 후 실기기로 재시연합니다.

## 문제 보고

각 항목의 실패 시 화면 스크린샷과 함께 걷기 탭의 상태 표시를 기록해 주세요.
좌표는 앱 어디에도 저장되지 않으므로, 문제 재현에는 "어느 코스의 몇 번째
구간인지"만 알려주시면 됩니다.
