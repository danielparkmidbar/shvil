# 쉬빌 코인 프로젝트 — AI 에이전트 조직 구조

다니엘 쌤은 **오케스트레이터와만 대화**한다. 오케스트레이터가 지시를 과업으로 분해해 각 사업부 대표 에이전트에게 분배하고, 산출물을 검증한 뒤 요약 보고한다.

## 확정 파라미터 (모든 에이전트 공통 — 변경 시 오케스트레이터 승인 필요)

- 발행: 인증 경로 검증 도보 1km = 1 SHV, 1인 1일 상한 40 SHV
- 권장 가격: 잠자리 10 / 식사 5 / 샤워 3 / 하루 풀 패키지 18 SHV
- 1단계 서버 원장(폐쇄형 포인트) → 2단계 저에너지 PoS 토큰 전환. PoW 배제
- 프로모션: 엔젤 등록 20 + 첫 접대 30 SHV (선착 500가정, 기간 한정)
- 제네시스 리저브: 인프라(쉬빌 홈) 투자 목적, 공개·용도 제한·베스팅 원칙
- 대원칙: 자원봉사 정신이 근본. 엔젤은 코인과 무관하게 수용 여부를 스스로 결정한다

## 운영 프로토콜 (지시 → 확인)

1. **지시 접수** — 오케스트레이터가 과업 정의(담당 사업부, 완료 기준, 산출물 형식)
2. **분배** — 대표 에이전트가 서브 에이전트에 배분, 병렬 가동
3. **산출** — 모든 결과는 파일로. 구두 보고는 산출물로 인정하지 않음
4. **검증** — 완료 기준 대조 + 확정 파라미터 일치 검사 + 문서 간 상충 검사. 중요 산출물은 독립 검증 에이전트 교차 검토
5. **보고** — 다니엘 쌤에게는 결정 필요 사항과 요약만. 미해결 쟁점은 각 설계서의 쟁점 목록에 누적

## Claude Code에서 팀 가동하는 법

1. 개발 레포에 `.claude/agents/` 폴더를 만들고 위 정의문을 에이전트별 md 파일로 저장
2. 각 파일 상단에 frontmatter 작성: `name`, `description`(위 역할 정의문), `tools`
3. 기준 문서 4종(프로토콜·지갑·신뢰안전·리저브 설계서)을 레포에 포함시켜 에이전트가 참조하게 함
4. 오케스트레이터 역할은 메인 Claude 세션이 담당 — 이 문서를 CLAUDE.md에 링크하면 운영 프로토콜이 자동 적용됨
