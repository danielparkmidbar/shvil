## ⚠ 다니엘 쌤 결정이 필요한 항목 (밀어붙이지 않고 남김)

### 1. 별점 근본 진위 (R-1d) — docs/별점_프라이버시_결정.md
- **현황**: 프라이버시는 견고(서버가 투숙 관계 모름). 그러나 안 B 특성상 **프로필
  주인이 자기 별점을 날조 가능**(위조 방지=서버가 평가자 신원 파악=프라이버시 붕괴,
  둘은 양립 불가). 지금은 "참고 지표 — 검증된 값 아님"으로 정직 표시 + 완화(낯선
  가짜 거름·rate-limit)만 했다.
- **선택지**: (현행 유지, 참고용) / (서버 서명검증 = 프라이버시 순간 양보) /
  (커밋-리빌 = 복잡하나 양쪽 확보).
- 파일럿에서 "참고용"으로 쓰는 건 현 상태로도 안전.

### 2. 스팟 보물 재설계 (M12) — docs/몸인증_보물마이닝_설계.md 4장
- 무기명 벽-QR 코인 바우처를 폐기했다(구조적으로 이중지불 방어 불가).
- **사업자 코인 지급**은 이미 대면 지불로 됨. **손님이 스캔만 하면 코인**(무인 벽 QR)은
  보물 마이닝(M9) 서버 회계 기반으로 재설계 예정 — 코인 예치/소각 흐름을 신중히
  설계하고 적대적 검증 통과 후 파일럿에. 서두르지 않음.

### 3. 동행 연락 핸들 공개 수위 (R-6)
- 게시판은 닉네임 표시 + 연락 라우팅용 authorMemberId·messagingPublicKey 공개
  (기존 GET /angels와 동일 방식, 가명 ID). 확정 팀 관계는 저장 안 함.
- 더 강한 프라이버시(핸들도 숨김)를 원하면 서버 중계가 필요한데, 그건 "X가 Y 글에
  관심"을 서버가 알게 되어 오히려 프라이버시가 약해진다. 현행이 관계 비저장에 더 부합.
