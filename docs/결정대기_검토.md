## 🔴 핵심 결정 (다른 작업을 여는 것 / 사업·철학 판단)

### 1. 협약 스테이블코인·체인 (지시서 8.1)
- 현황: 마켓 에스크로는 Mock 체인 어댑터로 구현·검증 완료. 확정 시 동일 인터페이스로 실체인 어댑터만 연결.
- **권고: USDC on Base.** 근거 — 저에너지 L2, 가스 대납(가스리스) 성숙, 낮은 수수료가 소액 결제(3~18 SHV)에 적합. 대안: Polygon PoS(도구 성숙), Celo(모바일·전화번호 매핑).
- 확정 시 열리는 작업: 지갑 USDC 잔액·수신, 마켓 실결제, 테스트넷 E2E.

### 3. 앱 무결성 증명(Play Integrity / App Attest) 민팅 필수화 (지시서 8.3)
- 현황: 훅만 존재(기본 off). **보안 감사 C-2 = 릴리스 차단 사유.** 지시서 3장이 위조 방지의 뿌리로 명시한 방어선.
- **권고: 필수화.** 헌법 제3조(속도보다 진리)에 부합. 이것 없이는 변조 앱으로 위조 코인 생성이 가능해 파일럿 착수 불가.
- 확정 시 작업: 실토큰 연동 + 회원 번호↔기기 키 서버 서명 결속.

### 5. 마켓 수수료율 (지시서 8.5)
- 현황: 2.5%로 구현(설정값). 대면 지불은 영구 무료.
- **권고: 2.5% 확정.** 운영 재원 최소 수준. 헌법 제2조(무투자·비영리)와 충돌 없음 — 투명성 페이지 공시.

### 6. 파일럿 시작 구간·초기 엔젤 좌표 수집 (지시서 8.6)
- 현황: 내장 코스는 쉬빌 이스라엘 북부 *샘플* 좌표. 확정 필요.
- **다니엘 쌤 결정 필요:** 파일럿 구간(예: 쉬빌 이스라엘 북부 실구간) + 초기 엔젤 좌표 수집 방법(기존 위키쉬빌·WhatsApp 커뮤니티 접촉 등). 현장 사안.

### 9. 격려 코인 프로모션 총량·기간 (지시서 8.9)
- 현황: 완주 10 / 구간 3 SHV로 구현, 1인 1코스 1회. 총량·기간 미설정.
- **권고: 보상액 10/3 확정.** 총량·기간은 초기 활성화 목적이므로 다니엘 쌤이 예산 관점에서 상한 지정(예: 총 5,000 SHV 또는 3개월).

### ✅ 확정 — R-스팟-현장결속. 스팟 청구에 몸-걸음 인증 결합 (2026-07-18 다니엘 쌤)
- **결정: 결합 확정** ("push 하고 스팟 현장결속 진행해"). 기본 요구 + 사업자 선택 해제(`requirePresence:false` — 식당·주유소 즉시 스캔 원안 보존, 끄면 V-1 위험을 그 스팟이 진다).
- **구현 완료 (M14)**: 서버 1회용 랜덤 지시(`POST /spot/challenge`, CSPRNG·TTL 5분·재사용/도용/재시도 차단) + 폰 로컬 근접·변위 판정(M9와 엔진 공용) + 서버 대조(지시 일치·최소 소요 시간·걸음 대역). 서버는 좌표를 받지 않는다 — 남는 것은 수행 요약 해시뿐. 상세: `몸인증_보물마이닝_설계.md` 4-3장.
- 남는 한계(정직화): 변조 앱의 걸음 위조는 앱 무결성 인증·소명 책임의 몫(코인 발행 전체와 동일 한계). V-4(정찰)는 기능 요건의 귀결로 존치.

## 🟢 권고대로 확정 제안 (이미 구현 / 이견 적음)

### 2. 코스 회랑 폭 + 엔젤 우회 한도 (지시서 8.2)
- **권고: 지형별 차등 확정** — 개활지 50m / 삼림 75m / 산악 100m / 도심 150m (프로토콜 1.5절, 구현됨). **엔젤 우회 편도 5km 확정**(구현됨). 구간 속성이라 코드 배포 없이 조정 가능.

### 4. 니모닉 백업 강제 여부 (지시서 8.4)
- **권고: 강제 아님 + 첫 10 SHV 형성 시 강력 권고 UI.** 단, 니모닉 복구는 **현재 미구현**(감사 L-2) — 파일럿 전 구현 필요. 확정 코인만 복구, 잠정 누적 제외.

### 7. 요율 확정 (지시서 8.7)
- **권고:** 코스 이탈 감액 **1/10 확정**, 난이도 계수 상한 **×4.0 확정**(둘 다 구현됨). 일상 걸음 미세 요율은 🔴 아래 질문 참조.

### 8. 클레임 구제 기준 (지시서 8.8)
- **권고: 인정 투표 5명 / 월 2회 확정**(구현됨). 남용 방지와 접근성의 균형. 파일럿 데이터로 재튜닝.

### 10. 엔젤 우회 잠정분 소멸 시점 (M0 추가)
- **권고: 현 구현 확정** — 정산 시 지불 대상 엔젤의 우회분만 확정, 나머지(다른 엔젤·수동 정산)는 소멸. 지시서 0-6 사상에 정합.

### 11. 코인 분할(잔돈) 스키마 (M0 추가)
- **권고: 현 구현 확정** — 소유자가 자식 금액 전체를 서명 커밋(합계=부모), 계보·회원 번호는 뿌리 상속. 수신 지갑 로컬 검증 가능.

### 12. 인간 한계 주간 상한 (M0 추가 / 감사 관련)
- **권고: 300 SHV/7일 확정**(구현됨). 지시서 3장 "주 300 SHV 물리적 불가능" 예시 준용. 지역별 탑 100 기준선 축적 후 실측 튜닝.

### 13. 미세 요율 잔여분 이월 (M0 추가)
- **권고: 현 구현 확정** — 0.1 SHV 미만 잔여만 익일 이월(일상 미세 요율이 실제로 쌓이게), 일일 상한 초과 절사분은 이월 금지(상한 무력화 방지).
