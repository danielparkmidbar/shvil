# 실기기 시험 절차 — 분당 불곡산

> 다니엘 쌤이 직접 폰을 들고 하시는 시험입니다.
> **화면에 보이는 글자만으로** 설명합니다. 코드를 열 필요가 없습니다.

---

## 미리 아셔야 할 것 세 가지

**① 얼마가 나오는지 미리 알려 드립니다 — 놀라지 마세요.**

| | 나와야 하는 값 |
|---|---|
| 이마트 분당점 → 불곡산 정상 **편도** | **2.2 SHV** |
| 다시 내려와 **왕복** | **4.4 SHV** |
| 걷는 거리 | 편도 약 1.8 km (30분 정도) |

지시서에 적혀 있던 "1.55 km = 1.5 SHV"는 **옛 숫자입니다.** 두 가지가 바뀌었습니다.
코스 좌표가 손으로 그린 선에서 **실제 등산로**로 바뀌어 길이가 1.55 → 1.82 km가 됐고,
1.5라는 계산은 **산길 가산(1.5배)을 빼먹은 값**이었습니다.

**2.2가 나오면 정상입니다. 2.0이나 2.3이 나와도 정상입니다** (창 경계에서 조금씩
잘리므로 ±0.2 정도는 흔듭니다). **1.5나 0.5가 나오면 무언가 잘못된 것입니다** —
아래 "잘못됐을 때" 표를 보세요.

**② 왕복하시면 샤워값(3 SHV)을 실제로 낼 수 있습니다.**
편도만 걸으면 2.2 SHV라 3 SHV 지불 시험을 못 합니다. **왕복을 권합니다.**

**③ 가입하지 않아도 전부 됩니다.**
걷기·정산·지불·수령이 가입 없이 끝까지 됩니다. 첫 시험은 **가입하지 말고** 해 보세요.
그게 "설치하고 걸으면 끝"이 정말인지 보는 시험입니다.

## 1. 준비물

### 1-1. 폰

- **안드로이드 폰 2대**를 권합니다. 1대로도 걷기·정산까지는 되지만,
  **주고받기 시험은 2대가 있어야 합니다** (한 대가 QR을 띄우고 다른 대가 찍습니다).
- 두 대 다 배터리를 충분히 채워 두세요. 화면을 계속 켜 둡니다.

### 1-2. 앱 설치

APK 파일을 두 대에 각각 설치합니다.
설치할 때 "출처를 알 수 없는 앱" 경고가 뜨면 허용해 주세요.

### 1-3. 서버가 깨어 있는지 확인 (집에서, 출발 전에)

폰 브라우저 주소창에 이렇게 칩니다.

```
shvil-directory.onrender.com/courses
```

- **글자가 잔뜩 나오면 정상입니다.**
- **1분 가까이 하얗게 멈춰 있어도 정상입니다.** 서버가 자고 있다가 깨어나는 중입니다.
  하얗게 있다가 오류가 나면 **한 번 더** 새로고침하세요. 두 번째는 2초 만에 뜹니다.

★이 확인을 **출발 전에** 해 두세요. 서버가 깨어 있어야 나중에 가입 같은 것이 됩니다.
걷기·지불 자체는 서버가 죽어 있어도 됩니다.

### 1-4. 권한 (앱을 처음 열면 물어봅니다)

| 물어보는 것 | 반드시 |
|---|---|
| 위치 | **"앱 사용 중 허용"** |
| 신체 활동 / 피트니스 | **허용** (걸음 수를 세는 데 씁니다) |
| 카메라 | **허용** (QR을 찍습니다) |

★**세 개 다 허용해야 합니다.** 하나라도 거부하면 아래 "잘못됐을 때" 표의 증상이 나옵니다.

## 2. 걷기 전에 확인할 화면 (이마트 앞에서, 아직 걷지 말고)

앱을 열면 아래에 탭이 있습니다: **홈 · 걷기 · 지갑 · 거래 · 더보기**

### 2-1. 홈 탭

1. 맨 아래 초록 버튼 **"걷기 추적 시작 (만보기 모드)"** 를 누릅니다.
2. 버튼이 빨간 **"걷기 추적 중지"** 로 바뀌면 시작된 것입니다.
3. **버튼 아래에 빨간 ⚠ 글자가 뜨면 걷지 마세요.** 무엇이 잘못됐는지 그 자리에
   적혀 있습니다. 고치고 다시 시작하세요.

### 2-2. 걷기 탭 — 여기가 시험의 계기판입니다

**"현재 상태"** 칸에 색 딱지가 하나 뜹니다.

| 딱지 글자 | 뜻 |
|---|---|
| **코스 위 — 인정 중 (기준 요율)** | ✅ 좋습니다. 이게 나와야 합니다 |
| 코스 밖 — 미세 생성 (일상과 동일) | 코스에서 벗어났습니다 |
| 대기 중 | 아직 위치를 못 잡았습니다 |

그 아래 **"코스: Bundang E-mart - Bulgoksan Peak (pilot)"** 이 보이면
폰이 이 코스를 알아본 것입니다.

**"GPS 상태"** 칸을 봅니다.

| 보여야 하는 것 | 뜻 |
|---|---|
| **정확도 ±12 m — 판정에 반영 중** (초록 글씨) | ✅ 좋습니다 |
| 이번 창 위치 12개 (최소 3개 필요) | ✅ 위치가 충분히 들어옵니다 |
| 거리 계측: 코스 선 위 진행량 (GPS 흔들림이 상쇄됩니다) | ✅ 코스 위에 있습니다 |

★**출발 전에 이 세 줄이 다 보일 때까지 기다리세요.** 30초쯤 걸릴 수 있습니다.
하늘이 보이는 곳에 서 계세요.

## 3. 걸으면서 볼 것

**폰은 손에 들거나 바지 주머니에 넣으세요.** 가방 안쪽 깊은 곳은 걸음이 잘 안 세집니다.

10분에 한 번쯤 **걷기 탭**을 봅니다.

| 볼 곳 | 정상 |
|---|---|
| 현재 상태 딱지 | **"코스 위 — 인정 중"** 이 계속 유지 |
| GPS 상태 · 정확도 | ±30 m 이하면 아주 좋고, ±100 m까지도 괜찮습니다 |
| **"이번 구간 (정산 전)"** 의 큰 숫자 | 걸을수록 **올라갑니다** |
| 그 아래 "1.2 km · 1,600 걸음" | 거리와 걸음이 같이 올라갑니다 |

**중간 점검 기준** (편도 1.8 km 기준)

| 걸은 정도 | 이번 구간 숫자가 대략 |
|---|---|
| 이마트에서 산 입구까지 (약 800 m, 평지) | 0.8 SHV 안팎 |
| 정상 도착 (1.8 km) | **2.2 SHV 안팎** |

★산길에 들어서면 숫자가 **더 빨리** 올라갑니다. 산길은 1.5배로 쳐 주기 때문입니다.
정상적입니다.

★**숫자가 한 번도 안 올라가면 그 자리에서 멈추고** 아래 "잘못됐을 때" 표를 보세요.
계속 걸어도 회복되지 않습니다.

## 4. 정산하기 (정상에서, 또는 다 내려와서)

★**왕복하실 거라면 정상에서 정산하지 마세요.** 내려와서 한 번에 정산하면 4.4 SHV가
됩니다. 정상에서 정산하면 2.2 SHV로 끊깁니다.

1. **걷기 탭** 맨 아래 주황 버튼 **"여기서 정산"** 을 누릅니다.
2. "잠정 누적 2.2 SHV를 지금 확정할까요?" 라고 물어봅니다. **"정산"** 을 누릅니다.
3. **"정산 완료 — 2.2 SHV 코인이 확정되었습니다."** 가 뜨면 성공입니다.

### 나와야 하는 값

| 걸은 방식 | 정산 |
|---|---|
| 편도 | **2.2 SHV** (2.0~2.4면 정상) |
| 왕복 | **4.4 SHV** (4.0~4.8이면 정상) |

**"확정할 잠정 누적이 없습니다"** 가 뜨면 → 아무것도 안 쌓인 것입니다.
"잘못됐을 때" 표를 보세요.

4. **홈 탭**으로 갑니다. **"확정 잔액"** 에 2.2 SHV가 들어와 있어야 합니다.

## 5. 지불 QR이 만들어지는지 (폰 한 대로도 됩니다)

1. **거래 탭** → 위쪽 **"🤝 수령"** 을 누릅니다.
2. **"샤워 3"** 버튼을 누릅니다 (왕복해서 4.4 SHV가 있을 때).
   편도만 걸었으면 아래 칸에 **2**를 쳐 넣고 "청구 QR 생성"을 누르세요.
3. **청구 QR**이 화면에 뜹니다. ✅ 여기까지 되면 청구는 정상입니다.

폰이 한 대뿐이면 여기서 QR을 **사진으로 찍어 두고**, 위쪽 **"📲 지불"** 로 바꿔서
그 사진을 스캔해 보실 수도 있습니다. 다만 **자기 자신에게는 지불이 완결되지 않습니다**
(같은 지갑이라 "이미 가진 코인"으로 걸립니다). 지불 QR이 **만들어지는지**까지만 봅니다.

## 6. 두 대로 주고받기 (진짜 시험)

**A폰 = 걸어서 코인을 만든 폰 (내는 쪽) / B폰 = 받는 쪽 (엔젤 역할)**

### 순서

**① B폰: 청구 QR 만들기**
거래 탭 → **🤝 수령** → **"샤워 3"** → 청구 QR이 뜹니다. **그대로 들고 계세요.**

**② A폰: 그 QR을 찍기**
거래 탭 → **📲 지불** → 카메라가 켜집니다 → B폰 화면을 비춥니다.
→ **"지불 확인 — 3.0 SHV"** 화면이 나옵니다 → **"3.0 SHV 지불"** 을 누릅니다.

**③ A폰: 지불 QR을 B폰에 보여 주기**
A폰에 **"지불 QR — 엔젤에게 보여주세요"** 가 뜹니다.

- QR이 **한 장**이면 그대로 들고 계세요.
- QR이 **여러 장**이면 화면이 저절로 넘어갑니다. 아래에
  **"9장 중 3번째"** 처럼 표시됩니다. **넘어가는 대로 그냥 들고 계세요.**
  순서는 상관없습니다.

**④ B폰: A폰 화면 찍기**
B폰에서 **"지불 QR 스캔 (역스캔)"** 을 누릅니다 → A폰 화면을 비춥니다.

- 한 장이면 바로 넘어갑니다.
- 여러 장이면 화면 아래에 **"4 / 9장 모았습니다 — 화면을 계속 비춰 주세요"** 가
  뜹니다. 숫자가 올라갈 때까지 계속 비추세요. 다 모이면 저절로 넘어갑니다.
- **숫자가 한동안 안 올라가면** 두 폰을 조금 더 가까이 / 멀리 해 보세요.
  A폰 화면 밝기를 최대로 올리면 잘 읽힙니다.
- 너무 빨리 넘어가서 못 찍겠으면, A폰의 **"넘기는 속도: 400ms — 눌러서 바꾸기"** 를
  눌러 느리게 하세요.

**⑤ B폰: 받을지 정하기**
- 아무 문제가 없으면 **바로 "수령 완료"** 로 넘어갑니다 (가입하지 않은 폰끼리는 이쪽입니다).
- **"받으시겠습니까?"** 화면이 뜨면, 금액·상대·코인 내역을 보고
  **"3.0 SHV 받습니다"** 또는 **"안 받겠습니다"** 를 고릅니다.
  ★"안 받겠습니다"를 눌러 보셔도 됩니다 — **상대의 코인은 없어지지 않습니다.**
  다시 ④부터 하면 됩니다. (이것도 시험해 볼 가치가 있습니다.)

**⑥ B폰: 확인 QR을 A폰에 보여 주기**
B폰에 **"수령 완료 — 확인 QR을 리스트에게 보여주세요"** 가 뜹니다. 들고 계세요.

**⑦ A폰: 확인 QR 찍기**
A폰에서 **"엔젤의 확인 QR 스캔"** 을 누르고 B폰 화면을 비춥니다.
→ **"지불 완료 — 3.0 SHV가 엔젤에게 전달되었습니다."**

**⑧ 양쪽 잔액 확인**
- A폰 홈 탭 확정 잔액: 3.0 SHV **줄어 있어야** 합니다
- B폰 홈 탭 확정 잔액: 3.0 SHV **늘어 있어야** 합니다

✅ 여기까지 되면 **지갑이 끝까지 작동한 것입니다.**

### 시험해 보면 좋은 것 하나 더 — 두 번째 바퀴

B폰이 받은 그 코인으로 **다시 A폰에게** 내 보세요 (①~⑦을 반대로).
이게 헌법 제7조가 말하는 "받은 선행을 다시 베푸는 것"이고, 지금까지 **여기서 막혀
있던** 자리입니다. 코인이 손을 한 번 바꿨으므로 QR이 더 커져서 **여러 장으로
나뉠 가능성이 높습니다.** 그래도 완결되어야 합니다.

## 7. 잘못됐을 때 — 증상별 원인

### 걷기가 안 될 때

| 화면에 보이는 것 | 원인 | 하실 일 |
|---|---|---|
| 홈에서 시작을 눌러도 빨간 **⚠ 위치...** 글자가 뜬다 | 위치 권한 거부 | 폰 설정 → 앱 → 쉬빌 → 권한 → 위치 **허용** |
| **⚠ 이 기기에서 만보기를 쓸 수 없습니다** | 걸음 센서가 없거나 신체 활동 권한 거부 | 설정에서 "신체 활동/피트니스" 허용. 그래도 안 되면 **다른 폰으로** — 이 상태로 걸으면 하루 걸어도 0이 나옵니다 |
| 걷기 탭 GPS 상태가 계속 **"첫 위치를 기다리는 중…"** | 아직 위성을 못 잡음 | 건물 밖, 하늘이 보이는 곳에서 30초~1분 기다리기 |
| 상태 딱지가 계속 **"대기 중"** | 추적을 시작 안 했거나 위치가 아직 없음 | 홈 탭에서 버튼이 **빨간색("중지")** 인지 확인 |
| **정확도 ±250 m — 너무 부정확해 이 위치는 제외** (빨간 글씨) | 실내·터널·지하 | 밖으로 나오기. ±200 m까지는 인정합니다 |
| **"이번 창 위치 1개 (최소 3개 필요)"** 가 계속 | 폰이 절전으로 위치를 끊고 있음 | 화면을 켜 두기. 설정 → 배터리 → 쉬빌 → **최적화 안 함** |
| 상태가 **"코스 밖 — 미세 생성"** | 등산로에서 벗어남 | 원래 길로 돌아오기. 100 m 안쪽이면 대개 다시 "코스 위"가 됩니다 |
| **⚠ 가짜 위치(mock location) 감지** | 개발자 옵션의 모의 위치 앱이 켜져 있음 | 설정 → 개발자 옵션 → 모의 위치 앱 **없음**으로 |
| 거리는 오르는데 **걸음이 0** | 폰이 흔들리지 않음 (가방 안쪽) | 손에 들거나 바지 주머니에 |

### 정산이 이상할 때

| 증상 | 원인 | 하실 일 |
|---|---|---|
| **"확정할 잠정 누적이 없습니다"** | 코스 위 걸음이 하나도 인정 안 됨 | 걷기 탭 GPS 상태 카드를 보세요. 대개 **만보기** 아니면 **정확도**입니다 |
| **0 SHV** 로 정산됨 | 같은 이유 | 위와 같음 |
| **1.5 SHV 근처**가 나옴 | 산길 구간이 인정 안 됨 (산에서 "코스 밖"이었을 가능성) | 산길에서 상태 딱지가 "코스 위"였는지 되짚어 보기 |
| **4 SHV 이상**인데 편도만 걸었다 | GPS가 심하게 흔들렸거나 코스를 여러 번 오갔음 | 기록해 두고 알려 주세요 (이건 우리가 봐야 합니다) |

### 주고받기가 안 될 때

| 증상 | 원인 | 하실 일 |
|---|---|---|
| 카메라가 켜지는데 아무 반응이 없다 | QR이 화면에 다 안 들어옴 / 너무 어두움 | 폰을 조금 멀리, 상대 화면 밝기 최대 |
| **"4 / 9장 모았습니다"** 에서 숫자가 안 올라감 | 같은 장만 계속 찍히고 있음 | 잠깐 카메라를 돌렸다 다시 비추기. A폰에서 **넘기는 속도**를 느리게 |
| **"조각을 다 모았지만 내용이 맞지 않습니다"** | 잘못 읽힌 조각이 섞임 | 그대로 계속 비추면 다시 모읍니다. 밝은 곳에서 다시 |
| **"청구 서명이 유효하지 않습니다"** | 청구 QR이 아닌 것을 찍음 | 순서 확인 — 지불하는 쪽이 먼저 찍는 것은 **청구 QR**입니다 |
| **"잔액 부족: 2.2 SHV < 3.0 SHV"** | 낼 돈이 모자람 | 왕복해서 4.4 SHV를 만들거나, 청구 금액을 2로 낮추기 |
| **"이미 가진 코인입니다"** | 한 대로 자기에게 지불함 | 정상입니다. 두 대로 하세요 |
| **"받으시겠습니까?"** 화면이 뜨고 **"내 지갑에 신뢰 키 목록이 없어..."** 라고 나온다 | 내는 쪽이 **가입한 폰**이고, 받는 폰은 아직 인터넷에 한 번도 연결되지 않음 | 정상입니다 — "확인은 못 했다"고 솔직히 말하는 것입니다. 그냥 **"받습니다"** 를 누르시면 됩니다. 받는 폰을 잠깐 인터넷에 연결하면 이 화면이 사라집니다 |
| 지불 화면에서 나가 버렸다 | | 거래 탭 **📲 지불**로 돌아오면 **그 지불 화면이 그대로 있습니다** |
| 앱을 껐다 켰더니 지불이 사라졌다 | 진행 중이던 지불은 앱을 끄면 사라집니다 | **코인은 그대로 있습니다.** 처음부터 다시 하세요 |

## 8. 시험 후에 알려 주시면 좋은 것

수첩에 적어 오시거나 스크린샷으로 남겨 주세요.

1. **정산 숫자** — 편도/왕복 각각 몇 SHV가 나왔는지
2. **걷는 동안 본 정확도** — 산길에서 ±몇 m였는지 (한두 번만 봐 주셔도 됩니다)
3. **"코스 밖"이 뜬 적이 있는지**, 있었다면 대략 어디에서
4. **QR이 몇 장으로 나뉘었는지**, 그리고 **몇 초 만에 다 찍혔는지**
   ★이게 지금 우리가 폰 없이는 알 수 없는 유일한 숫자입니다
5. **"넘기는 속도"를 바꾸셨는지**, 바꿨다면 몇 ms에서 잘 읽혔는지
6. 걸음 수가 실제 느낌과 많이 달랐는지

## 9. 이번 시험으로 확인되지 않는 것 (미리 말씀드립니다)

정직하게 적습니다 — 이 시험이 통과해도 **아래는 여전히 모릅니다.**

- **코스를 벗어났을 때 제대로 걸러지는가.** 불곡산 회랑이 넓어서(양옆 120~150 m)
  등산로에서 100 m 벗어나도 "코스 위"로 나옵니다. 회랑 판정은 여기서 시험되지 않습니다.
- **아이폰에서의 동작.** 위치를 받는 방식이 안드로이드와 다릅니다. 안 재 봤습니다.
- **코인의 무결성 증명.** 아직 붙지 않았습니다 — 파일럿 코인은 전부 "미확인" 상태입니다.
- **긴 종주에서의 동작.** 60일치 코인은 계산으로만 확인했습니다.

이 시험이 확인하는 것은 **"한 사람이 걸어서 돈을 만들고, 그 돈이 다른 사람 손으로
건너가는 것"** 입니다. 그것이 이 화폐의 전부이고, 그것이 되는지를 처음으로 폰으로
보는 것입니다.
